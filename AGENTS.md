# AGENTS.md

## Scope

Repository-specific guidance for AutoTranscribe2. Shared cross-project behaviors are in `~/.codex/skills/`; this file records only local exceptions and constraints.

## Operating Model

This repository relies on shared skills for commit discipline, change safety, repo hygiene, and observability defaults. `AGENTS.md` stays focused on what is specific to this project.

## Repository Context

- **Runtime**: Node.js v22 (nvm), TypeScript compiled to `dist/` via `tsc`.
- **Python backend**: parakeet MLX backend at `py-backend/`, uses `.venv/`.
- **Config**: `config.yaml` at repo root; runtime state in `runtime/`.
- **LaunchAgent**: autostart managed via `npm run autostart:install`, plist at `~/Library/LaunchAgents/com.autotranscribe2.startall.plist`.
- **Recordings/transcripts**: live under `~/Documents/AutoTranscribe2/` (outside repo).

## Repository-Specific Rules

- Always build before running: `npm run build && node dist/cli/...`
- Run `npm test` before committing; tests are in `src/__tests__/` and compile to `dist/__tests__/`.
- `startAll` is a one-shot launcher (spawns detached children and exits). The launchd plist uses `KeepAlive: { SuccessfulExit: false }` so it only retries on failure.
- Supervisor state is the source of truth for process health; see `runtime/managed-watcher-supervisor.json`.
- Do not modify `dist/` by hand; it is always regenerated by `tsc`.

None currently.
